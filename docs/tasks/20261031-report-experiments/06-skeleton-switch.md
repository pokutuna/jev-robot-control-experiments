## Goal

アウトラインの実験 4 の後半。017 の骨組み (3 つ目の版) を変えずに、タスクに固有の値だけを task 60 (左の黒いボウルをトレイへ) のものにして回し、運ぶ物を替えても骨組みが動くかを確かめる。

## Done When

- `experiments/018-skeleton-switch/` に init 0〜9 の記録、results.md、README がある
- 失敗があれば、どの段でどう失敗したかを動画と真値で確かめて README に書いている

## Context

- 値: `experiments/017-skeleton/programs/task60.py` (言い方は 016、縁を掴むずらし -6 cm は 015)
- 骨組みは task 61 の結果で直しているので、task 60 では直さない。直したくなったら、直さずに結果として書く

## Result

骨組みの 4 つ目の版 (置き場所に何も持たずに合わせて位置を覚える) で 3/10。掴む段は 10/10 で動いたが、置き場所の合わせが 5〜8 cm 手前で止まり、ボウルがトレイの縁に掛かった。3 つ目の版 (符号の誤りあり 10/10、直して 0/10) の記録と合わせて [README](../../../experiments/018-skeleton-switch/README.md) に書いた。物を持っている間の答えのずれは KNOWLEDGE "017" に足し、021、022 で LLM に渡す

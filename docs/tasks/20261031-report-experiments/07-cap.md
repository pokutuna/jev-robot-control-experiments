# 実験 019〜022: LLM が書く CaP のプログラムを、骨組みと比べる

ID: 07-cap
Bunch: ../20261031-report-experiments.md

## Goal

アウトラインの実験 5。骨組み (017、018) と同じ部品と、段ごとの確かめで分かったことを LLM に渡してプログラムを書かせ、task 61、60 で回す。渡す知見の量 (KNOWLEDGE "016" と "017") で、LLM のプログラムと結果がどう変わるかを、骨組みと比べる。

## Done When

- 019、020、021、022 に init 0〜9 のプログラム、記録、results.md、README がある
- README に、骨組みとの成功数、Jev の呼び出し、プログラムの手順の違いを書いている

## Context

- 019 (task 61)、020 (task 60) は KNOWLEDGE "016" (015、016 の知見)。021 (task 61)、022 (task 60) は "017" (016 に、017、018 で骨組みを回して分かった、指を開くと置き場所を押すこと、物を持っているときの向きの答えのずれ、を足したもの)。どちらも `src/s1cap/cap.py` の `KNOWLEDGE`
- "017" は測った事実だけで、骨組みの 4 つ目の版の解き方 (置き場所に先に合わせて覚える) は書いていない
- プログラムは `scripts/generate_programs.py` で init ごとに 1 本書かせる (deepseek/deepseek-v4.1-flash-1017)。回す前に読み、真値を使っていないかを確かめる
- dora は 1 つずつ回す。019 → 020 → 021 → 022 の順
- 骨組みの結果: 017 は 10/10、018 は 3/10 (置き場所の合わせが 5〜8 cm 手前で止まりボウルが縁に掛かる)

## Result

| タスク | 骨組み | LLM、"016" | LLM、"017" |
| --- | --- | --- | --- |
| 61 | 017: 10/10 | 019: 5/10 | 021: 8/10 |
| 60 | 018: 3/10 | 020: 6/10 (トレイごと持ち上げた 1 回を除くと 5/10) | 022: 4/10 (同じく除くと 3/10) |

- LLM は渡した知見 (言い方、開く前に 3 cm 上げる、持っている間は手首の x を使わない) をほぼ取り入れた。成否を分けたのは本ごとの書き方 (ループの上限、合わせる時機、置くときにずらすか) で、知見の違いの効果はばらつきと分けられない
- 失敗で多いのはループの上限が距離に足りないこと (019 で 4 回、021 で 2 回、022 で 3 回)
- 022 のボウルを持っているときのずれの補正は、018 で task 60 を回して測った値を書き写したもの。"017" には何も持たずに合わせると 5〜8 cm 手前で止まることが入っておらず、先にトレイに合わせてずらした本は 018 と同じく縁に掛かった

# 画像だけで Jev はロボットを動かせるかを、補助を段階的に足して確かめる

## Goal

計画 (`docs/cap-libero-idea.md` の 3 節) の実験 001〜005 (余裕があれば 006) を、共通の条件で回して結果を揃える。各実験について、成功率と、Jev が決めていることとコードが決めていることを、レポートと動画に使える形で `experiments/` に残す。

## Approach & Rules

### 実験の条件

- 共通の条件は計画の 3 節「共通の条件」に従う。libero_90 60、init state 0〜9 (足りなければ 0〜4)、判断の上限 120 回、成功は LIBERO の判定
- 方策には真値を渡さない。実験 001 だけが真値のテキストを入力にする。真値は評価 (向きの答えの正答率など) にだけ使う
- 前の実験との差分が 1 つになるように作る。問いの文や印を変えたら、その実験の README に書く
- 各実験の README には、目的、条件、結果 (成功率、判断の回数、費用、レイテンシ)、Jev が決めていることとコードが決めていること、失敗の仕方を書く

### 構成

- 実験に共通の実装は `src/s1cap/`、dora のノードは `nodes/`。実験ごとの dataflow と記録は `experiments/NNN-slug/` に置く
- 録画は代表的なものだけを git に入れ、残りは管理から外す
- 前の Bunch (`20261026-dora-nodes.md`) で作ったノード構成と命令の形式を使う ([dora-nodes.md](../../wiki/guides/dora-nodes.md))

### Constraints

- リポジトリは提出物で public。リポジトリ外のリソースは環境変数でパスを渡し、`docs/setup.md` に書く。API キーは `.env` にだけ置く
- uv で管理する。sim を動かすコマンドは `uv run --env-file .env` で実行する
- 締切は 2026-11-02 10:00。001、004、005 を揃えるのを最低限とする

### Conventions

- 作業で分かったことは `wiki/` に書く (`.claude/rules/wiki.md`)
- 結果は動画と真値で確かめてから報告する。LIBERO の判定だけで成功と言わず、軌跡と終わったときの状態も見る
- コミットはユーザに頼まれたときだけ行う

# 実験に使うタスクとその選び方

予備実験 (001〜011) は、libero_90 の task 60 (黒いボウルをトレイに入れる) だけで行った。その結果には、どの物を運んでも出てくるものと、ボウルだから出てきたものが混ざっている。これを分けるため、運ぶ物が 1 つで指の開きより小さいタスクを本筋にし、運ぶ物を替えたタスクと、運ぶ前に引き出しを開ける段を加えたタスクで難しさを上げる。レポートに使う実験は 012 から始め、これらのタスクで行う。この文書は、各タスクを選んだ理由と、それぞれで確かめたいことをまとめる。

物体の大きさは、衝突判定用の形状を囲む箱を、初期配置のままワールド座標の軸に沿って測った値 (幅 x × 奥行 y × 高さ z) である。指の開きは最大 8 cm である。

## task 60 でボウル固有だったこと

task 60 の結果のうち、次の 3 つはボウルとトレイの組み合わせから出てきた ([実験ごとの方策](policies.md))。

- ボウルの直径 10.7 cm は指の開きより大きいので、ボウルの中心ではなく縁を掴むしかない。Jev に問う向きも、中心ではなく縁に向けて問い直す必要があった (004-2、010)。
- 同じ形のボウルが 18 cm 隣にあるので、中心合わせが隣のボウルで止まることがある (003、008、011 の init 2)。
- トレイは浅く軽いので、離すときにトレイごと持ち上がることがある。

Jev の答えをロボットの動きに使えるかという問いに対して、これらは答えを分かりにくくする。掴み損ねたとき、Jev の向きが悪かったのか、縁を掴むための人の補正が足りなかったのかを分けられないからである。そこで、これらが起きにくいタスクを本筋にし、起きるタスクを後に回す。

## 段階

| 段 | タスク | 運ぶ物 | 置き場所 | 本筋から足される難しさ |
|---|---|---|---|---|
| 本筋 | libero_90 task 61 | プリンの箱 | トレイ | なし (基準) |
| 運ぶ物の切り替え | libero_90 task 62 | ドレッシングの瓶 | トレイ | 背が高く、掴む高さで倒れやすさが変わる |
| 運ぶ物の切り替え | libero_90 task 60 | 黒いボウル | トレイ | 縁を掴む、同じ形の物を左右で区別する |
| 高難易度 | libero_goal task 3 を改変 | クリームチーズの箱 | 閉じた引き出しの中 | 引き出しを開ける |

## 本筋と運ぶ物の切り替え: 箱や瓶をトレイに入れる (libero_90 task 61、62)

task 61 の指示文は「pick up the chocolate pudding and put it in the tray」、task 62 は「pick up the salad dressing and put it in the tray」である。どちらも task 60 と同じ LIVING_ROOM_SCENE4 を使う。

task 61 を本筋に選んだ理由は 2 つある。task 62 にも同じ理由が当てはまる。1 つ目は、task 60 と同じシーンなので、カメラの置き方、トレイ、固定カメラに印を描く高さ、sim と評価の仕組みを変えずに、運ぶ物だけを替えられることである。task 60 との差は、運ぶ物の形と、似た物があるかどうかに絞られる。2 つ目は、運ぶ物が場面に 1 つしかなく、指の開きより小さいことである。Jev に物への向きを問えば、その向きがほぼそのまま掴む場所への向きになるので、Jev の答えをロボットの動きに使えるかを、縁掴みの補正なしで確かめられる。ボウル 2 つは場面に残るが、運ぶ物とは見た目が違う。

| 物体 | 大きさ (cm) |
|---|---|
| chocolate_pudding_1 | 8.0 × 4.6 × 2.7 |
| new_salad_dressing_1 | 3.6 × 5.3 × 14.6 |
| akita_black_bowl_1、_2 | 10.7 × 10.7 × 5.1 |
| wooden_tray_1 | 29.7 × 16.7 × 8.2 |

2 つのタスクでは、物の位置と掴む場所のずれ方が違う。プリンの箱は長い辺 (8.0 cm) が指の開きと同じなので、短い辺 (4.6 cm) を挟む向きに手首を合わせる必要があるかもしれない。今の手順は手首を回さない。また高さが 2.7 cm しかないので、指を卓のすぐ上まで下ろす。ドレッシングは底面がどの向きでも指の開きに収まるが、高さが 14.6 cm あり、どの高さを掴むかで倒れやすさが変わる。本筋の手順は task 61 で組み、task 62 は、その手順が運ぶ物を替えても動くかを確かめるのに使う。

## 運ぶ物の切り替え: 左右のボウルを区別して入れる (libero_90 task 60)

予備実験と同じ task 60 で、本筋で外した 2 つの難しさを扱う。task 61 で組んだ手順を、運ぶ物の言い方と掴む場所を替えるだけで task 60 に使えるかを確かめる。予備実験の結果は見込みを立てるためだけに使い、レポートには 012 以降で行った結果を使う。

1 つ目は、同じ形の物を「左の」「右の」で区別できるかである。左右は画像の向きに合わせる。固定カメラの画像では左が −y である。手首カメラの画像は 180° 回してあるので、画像の右が +y、左が −y になり、固定カメラと左右がそろう。LIBERO には左のボウルを入れるタスク (task 60) しかないので、右のボウルも試すなら、指示文を変え、成功判定を akita_black_bowl_2 がトレイの中にあるかで行う独自の評価になる。

2 つ目は、物の位置と掴むべき場所が一致しないことである。予備実験では、Jev にボウルへの向きを問うとボウルの中心へ寄っていったが、中心では掴めないので、縁に向けて問い直した (004-2、010)。本筋のプリンの箱の向き、ドレッシングを掴む高さと合わせて、Jev に問えるのは物への向きであり、どこを掴むかは物の形から決まる知識として人か LLM が補う必要がある、という形でまとめる。

## 高難易度: 引き出しを開けてクリームチーズを入れる (libero_goal task 3 を改変)

libero_goal の task 3 は「open the top drawer and put the bowl inside」で、最初は閉じている棚の上の引き出しを開け、ボウルを中に入れる。このタスクを、入れる物だけクリームチーズに替えて使う。指示文は「open the top drawer and put the cream cheese inside」とする。

このタスクを選んだのは、運ぶ前に引き出しを開ける段が 1 つ入り、その前後の掴む、入れる段は本筋とほぼ同じだからである。本筋との差は、引き出しを開けることにほぼ絞られる。確かめたいのは、Jev に取っ手への向きを問えるか、引いて開ける動きを Jev の答えから作れるか、CaP で LLM が段の並びを組めるかである。

入れる物をボウルから替えたのは、ボウルにすると縁掴みの難しさが重なり、引き出しを開ける難しさと分けられなくなるためである。クリームチーズ (8.1 × 4.3 × 1.8 cm) はこのシーンに最初から置かれている平たい箱で、本筋のプリンの箱と似た掴み方で掴める見込みである。

LIBERO の標準タスクではないので、タスク定義 (BDDL) は task 3 のものを写し、指示文、成功条件、注目する物の 3 か所だけをクリームチーズに替える。物の顔ぶれは task 3 と同じなので、初期配置は task 3 の 50 通りをそのまま使う。次の点は確かめた。

- task 3 の初期配置を読み込むと、シミュレータの状態の次元 (79) が一致する。init 0 の初期状態では、成功判定は偽になる。
- シミュレータを直接操作して上の引き出しを開け、クリームチーズを中に移すと、成功判定は真になる。引き出しの中は、卓から約 17 cm 上にある。

取っ手を掴めるか、引き出しを引いて開けられるか、クォータービューから取っ手が見えるかは、まだ確かめていない。

## 選ばなかった候補

- libero_object (床の上の食品をかごに入れる 10 タスク): VLA の評価で広く使われる。ただし床の上なので、印を描く高さ、運ぶ高さ、カメラの置き方を決め直す必要がある。かごの高さは 14.1 cm で、トレイ (8.2 cm) より高い。本筋と比べて変わる条件が多いので外した。
- libero_spatial (同じ黒いボウルを位置関係で指して皿に置く 10 タスク): 縁掴みと同じボウルの問題がそのまま残り、task 60 と重なる。
- libero_90 task 55〜59 (LIVING_ROOM_SCENE3、食品をトレイへ): 同じ大きさでラベルだけが違う缶が並ぶ。本筋と性質が近く、task 61、62 なら task 60 と同じシーンを使えるので外した。
- libero_90 task 5 (KITCHEN_SCENE10、プリンを引き出しに入れて閉める): 引き出しが最初から開いているので、開ける段がない。
- libero_goal task 3 そのまま: 入れる物がボウルなので、縁掴みの難しさが重なる。

# 015 上から掴むときに許されるずれを、運ぶ物ごとに測る

## 課題

手順の骨組み (017) と CaP は、Jev の向きの答えで手先を運ぶ物の真上に合わせ、そこから下ろして当たって止まった所で指を閉じる。向きの答えは 2 cm 刻みの移動で、合わせた後も数 cm のずれが残る (016)。どれだけずれても掴めるかは運ぶ物の形で変わるはずだが、確かめていなかった。予備実験 006、011 では task 60 のボウルを縁で掴むと決めていたが、縁の点からのずれの許容は測っていなかった。この結果を、骨組みのタスクの値 (掴む点をずらす量、閉じる前に上げる量) と、CaP の LLM に渡す知見に使う。

## 仮説

- プリンの箱 (task 61) は y の幅 4.6 cm が指の開き 8 cm より小さいので、y のずれが 1〜2 cm までなら掴め、3 cm を超えると指が箱に載って掴めない。x のずれは、箱が x に 8 cm の長さを持つので影響が小さい
- ドレッシングの瓶 (task 62) は細いので、y の許容は箱より狭い
- 黒いボウル (task 60) は直径 10.7 cm で指の開きより広いので、縁を掴めば、縁の点から数 cm ずれても掴める

## 方法

`scripts/probe_grasp.py` が、Jev を呼ばずに、手先を決まった位置に置いてから掴む動きだけを繰り返す。

- 場面: libero_90 61、62、60。init state 0〜4
- 手先の位置: reset した後の始めの高さで、運ぶ物の位置 (真値) から x に -4〜+4 cm (2 cm おき)、y に -3〜+3 cm (1 cm おき) ずらした 35 か所の真上。ボウルは中心から y に -6 cm の縁の点を基準にした (`--center-dy -0.06`)
- 動き: 骨組みと同じ。3 cm ずつ下ろして当たって止まった所から 1.5 cm 上げ、指を閉じ、始めの高さまで持ち上げる。命令は dora の実験と同じ `RobotDriver` で送る
- 判定: 運ぶ物が 5 cm 以上持ち上がり、指の開きが 0.3 cm より大きければ掴めたとする

真値は手先を置くことと判定にだけ使う。

瓶がほとんど掴めなかったので、手先が卓まで下りられるかも測った (`reach`)。init 0 で、瓶の位置から y に +20 cm ずらした物の無い列で、x を -4〜+12 cm ずらした点ごとに、始めの高さから同じように下ろして止まった高さを記録した。

```sh
uv run --env-file .env scripts/probe_grasp.py run experiments/015-grasp-tolerance --task 61 --inits 0-4 --name pudding
uv run --env-file .env scripts/probe_grasp.py run experiments/015-grasp-tolerance --task 62 --inits 0-4 --name dressing
uv run --env-file .env scripts/probe_grasp.py run experiments/015-grasp-tolerance --task 60 --inits 0-4 \
    --center-dy -0.06 --name bowl_rim_minus
uv run --env-file .env scripts/probe_grasp.py reach experiments/015-grasp-tolerance --task 62
```

## 結論

- プリンの箱は、y のずれが -2〜+1 cm ならほぼ掴め、±3 cm では一度も掴めなかった。x は ±4 cm ずれても、y が合っていれば掴めた。仮説どおりで、骨組みでは箱の中心に合わせたまま下ろせばよい (`GRASP_SHIFT` は 0)
- ボウルは、中心から y に -6 cm の点を基準にすると、x に ±2 cm、y に ±3 cm ずれても 105 回中 102 回掴めた。失敗は x に 4 cm ずれ、さらに y に -2〜-3 cm (ボウルの外側) にずれた所に集まった。縁は円なので、x にずれると指の間に縁が入らなくなるためと考える (画像では確かめていない)。骨組みでは、ボウルの中心に合わせてから y に -6 cm ずらして下ろす
- ドレッシングの瓶は、指が瓶に当たる前に腕が止まった。物の無い所でも、瓶の x では 0.62 m より下に下りられないので、手先を真下に向けたままこの位置の物を掴むことは、この制御ではできない。これは向きの答えや掴む点の問題ではないので、task 62 は骨組みと CaP の比較から外す

x が -0.151 で 0.485 で止まった理由は確かめていない。

## 次へ

- 骨組み (017) のタスクの値を、この結果から決める (task 61 は `GRASP_SHIFT` 0、task 60 は y に -6 cm)
- CaP (019) の LLM に渡す知見に、物ごとの掴める範囲と、瓶の位置まで下りられないことを含める (`s1cap.cap.KNOWLEDGE["016"]`)
